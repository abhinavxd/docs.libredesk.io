title: Translations
description: Help translate libredesk into different languages
---

libredesk translations are managed on Crowdin. Pick a language, translate the untranslated strings, and the translations sync back into the app.

<Card title="Translate libredesk" icon="language" href="https://crowdin.com/project/libredesk">
  libredesk on Crowdin
</Card>

In pull requests, edit only `i18n/en-US.json`. The other language files come from Crowdin.
