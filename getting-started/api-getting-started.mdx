## Generating API keys

You need the `users:manage` permission to generate API keys.

<Steps>
  <Step title="Open the agent">
    Go to **Admin → Teammates → Agents** and open the agent.
  </Step>
  
  <Step title="Generate an API key">
    Click **Generate API key**. libredesk shows an API key and an API secret for that agent.
  </Step>
  
  <Step title="Save the credentials">
    Copy both values and store them securely. The secret is shown only once.
  </Step>
  
  <Step title="Key management">
    Regenerate or revoke the key at any time from the same page.
  </Step>
</Steps>

A request made with an API key has the same roles and permissions as the agent that owns the key.

## Using the API

All endpoints are under `/api/v1`. libredesk supports two authentication schemes:

### Basic authentication

```bash
curl -X GET "https://your-libredesk-instance.com/api/v1/endpoint" \
  -H "Authorization: Basic <base64_encoded_key:secret>"
```

### Token authentication

```bash
curl -X GET "https://your-libredesk-instance.com/api/v1/endpoint" \
  -H "Authorization: token your_api_key:your_api_secret"
```
