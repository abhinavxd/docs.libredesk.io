## Authentication

The API supports two authentication methods:

### Basic authentication
```bash
curl -X GET "https://your-instance.com/api/v1/endpoint" \
  -H "Authorization: Basic <base64_encoded_api_key:api_secret>"
```

### Token authentication
```bash
curl -X GET "https://your-instance.com/api/v1/endpoint" \
  -H "Authorization: token api_key:api_secret"
```

## Getting API keys

1. Go to **Admin → Teammates → Agents** and open the agent.
2. Click **Generate API key**.
3. Copy both the API key and the API secret. The secret is shown only once.

## Base URL

```
https://your-instance.com/api/v1
```

## Response format

Responses are JSON. A successful response wraps the result in `data`. An error response has a `message` and an `error_type`.
